## Interpretation

- ORCHARD includes FLAME and Community; the old standalone FLAME menu label is replaced by one ORCHARD entry.
- Bridges-2 has a scheduled full outage from November 9, 2026 at 05:00 Eastern for about 4–6 weeks; check PSC before future use.
- Neocortex is Cerebras, not a CUDA GPU cluster; a distinct integration would be needed. The public page gives inconsistent CS-3 counts, so no count is advertised.
- Atlas/Boston hardware is not established here; their public LTI guide identifies HPC resources. MLD publishes a GPU resource without a stable public cluster name; do not infer physical independence from private named systems.
- CPU-documented QCD/CAPS and workstation pools are labeled by kind rather than represented as uniform NVIDIA/Slurm clusters.
- The search covered SCS/CSD/LTI/MLD/RI, Engineering/ECE/MCS/Math/Physics/Chemistry, central ORCD/Computing Services/PSC, Dietrich/NI/CNBC/SEI and targeted Heinz/Tepper/Qatar/Silicon Valley searches. No named system found in a unit is a coverage gap, not evidence of no hardware.

The [PSC migration notice](https://www.psc.edu/b2-migration-2026/) supports the Bridges-2 outage warning. PSC is a [joint CMU/University of Pittsburgh center](https://www.psc.edu/about/), not CMU-exclusive hardware. Departmental sponsorship, PI allocations, instructional eligibility and other operator rules vary; see the [machine-readable inventory](cmu-clusters-20261107.json) for access limits and aliases.

## UI behavior

Only Wright has a non-null backend target. Future rows have gray text and `aria-disabled`, reject clicks, and are skipped by keyboard selection. The cluster dropdown spans both selector columns and scrolls within the widget. Planned systems appear at the bottom. No inference is triggered by viewing the menu.

Rebuild the local bundle with `cd frontend && npm run desktop:bundle`, quit the previous widget, then open `frontend/release/CMUTuneIt.app`. The generated bundle and local research working files remain ignored; reviewed source and code are tracked.
